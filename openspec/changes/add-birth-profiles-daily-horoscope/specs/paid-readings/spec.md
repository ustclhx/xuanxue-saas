# Spec Delta

## ADDED Requirements

### Requirement: 报告输入与档案解耦
用档案预填的输入解锁详批时，报告 SHALL 保存解锁当时的输入快照，MUST NOT 引用档案。之后修改或删除档案，SHALL NOT 改变已有报告的输入与内容。解锁意图令牌和登录、支付回跳地址只沿用原有的分享输入，MUST NOT 新增档案 id，也 MUST NOT 新增档案中的姓名等个人信息字段。

#### Scenario: 修改档案后打开旧报告
- **WHEN** 用户用档案生成报告后，把该档案的出生时间改掉
- **THEN** 旧报告的输入与正文保持不变

#### Scenario: 档案预填后解锁
- **WHEN** 已登录用户用档案预填八字表单并点击解锁
- **THEN** 解锁流程与手动填写时相同，报告基于服务端复算的命盘生成
