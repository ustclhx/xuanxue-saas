# Spec Delta

## ADDED Requirements

### Requirement: 从档案填入与存为档案
已登录用户在需要出生资料的工具表单中，SHALL 能「从档案填入」，也 SHALL 能把当前输入「存为档案」。双人表单的每一方都可以分别选择档案。

只有用户主动打开档案选择时，系统才读取档案。页面加载、未登录访客与离线计算 MUST NOT 因此发出请求或受到影响。填入后的计算仍在浏览器本地完成。

#### Scenario: 从档案填入八字表单
- **WHEN** 已登录用户在八字排盘页点击「从档案填入」并选择一份档案
- **THEN** 表单字段被填入，提交后结果在本地显示

#### Scenario: 未登录访客
- **WHEN** 未登录访客打开工具页
- **THEN** 页面不读取档案，不显示档案选择器，表单与原来一样可用

#### Scenario: 宫合双人选择
- **WHEN** 用户在사주궁합页为两个人分别选择两份档案
- **THEN** 两组表单分别被填入对应档案

#### Scenario: 存为档案
- **WHEN** 已登录用户得到结果后点击「存为档案」并确认关系
- **THEN** 新档案出现在档案列表中，表单内容不变
