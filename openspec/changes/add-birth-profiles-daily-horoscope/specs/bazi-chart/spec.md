# Spec Delta

## ADDED Requirements

### Requirement: 流日关系
给定一个公历日期，排盘引擎 SHALL 返回以下结果：
- 当日日柱干支、农历日期，以及黄历的宜、忌与建除十二值星；
- 给定本命盘时，另外返回：当日日干相对日主的十神，当日日支与本命年、月、日、时各支的六冲、六合、三合、三刑、六害关系。时辰未知时只比较三支。

计算 MUST 是确定性的，换日采用民用日界（00:00），结果 SHALL 带规则版本号。

#### Scenario: 当日日柱
- **WHEN** 计算 2026-11-13 的流日
- **THEN** 返回该日的日柱干支，与工具页万年历显示的日柱一致

#### Scenario: 日支冲本命
- **WHEN** 本命日支为辰，当日日支为戌
- **THEN** 结果标出「日支 辰戌冲」

#### Scenario: 时辰未知
- **WHEN** 本命盘不知道时辰
- **THEN** 只返回与年、月、日三支的关系，不报错
