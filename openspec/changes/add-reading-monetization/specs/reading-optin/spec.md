# Spec Delta

## Purpose

在免费结果之后以零成本收集愿意接收个性化解读的访客邮箱，形成可持续触达的名单，同时不打断首屏体验。

## ADDED Requirements

### Requirement: 结果后订阅卡片
结果显示后 SHALL 在结果区块之后显示内联订阅卡片，字段为姓名（可选）、邮箱、主题下拉（本语言的爱情、事业、财运、复合、自我成长）；卡片 MUST NOT 以弹窗形式出现，也 MUST NOT 早于结果出现。

#### Scenario: 卡片位置
- **WHEN** 结果显示
- **THEN** 订阅卡片位于结果区块之后，页面没有弹窗

### Requirement: 个性化解读邮件
订阅确认后 SHALL 发送一封本语言邮件，内容为该次结果的摘要解读（按所选主题选取模板段落）、指向结果页的链接与完整分析入口；邮件 SHALL 包含退订链接与合规声明。

#### Scenario: 确认后收到解读
- **WHEN** 访客提交八字结果的订阅并点击确认链接
- **THEN** 收到包含其日主与所选主题解读段落的繁中邮件
