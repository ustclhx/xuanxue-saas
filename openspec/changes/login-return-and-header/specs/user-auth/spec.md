## ADDED Requirements

### Requirement: 登录后的去向
用户成功登录后 SHALL 回到发起登录的页面：登录请求携带的回跳地址通过本站校验时，回到该地址（保留语言前缀）；没有回跳地址、或回跳地址未通过校验时，回到站点首页。登录成功后 MUST NOT 默认进入 `/app` 空间页。账户中心与接受邀请的既有回跳保持不变。

#### Scenario: 从工具页登录后回到原页面
- **WHEN** 访客在东方站 `/ko/` 的某个工具页点击「登录」，完成登录
- **THEN** 浏览器回到该工具页，地址与语言前缀不变

#### Scenario: 直接访问登录页
- **WHEN** 访客直接打开 `/login`（没有回跳地址），完成登录
- **THEN** 浏览器进入站点首页，而不是 `/app`

#### Scenario: 回跳地址不合法
- **WHEN** 登录页收到指向其他站点或 `/api` 路径的回跳地址
- **THEN** 忽略该地址，登录后进入站点首页

#### Scenario: 邮箱验证完成后的继续入口
- **WHEN** 用户在邮箱验证成功页点击「继续」
- **THEN** 浏览器进入站点首页
