# Spec Delta

## MODIFIED Requirements

### Requirement: 解锁入口
免费结果末尾 SHALL 显示「完整分析」入口，内容包括所需积分、按界面语言确定的价格以及报告章节目录。价格的显示方式如下：

- zh-Hant 与 ko 显示实际结算的本地币种价格；
- zh-Hans 显示美元价格并附人民币参考价；
- en 显示美元价格。

该入口 MUST NOT 遮挡免费结果。

#### Scenario: 查看价格
- **WHEN** 访客在韩语界面看到八字结果末尾的完整分析入口
- **THEN** 入口显示所需积分、按韩元结算的价格（如 ₩2,800，不带「约」）与章节目录

#### Scenario: 简体界面
- **WHEN** 访客在简体界面看到完整分析入口
- **THEN** 入口显示美元价格与标注为参考价的人民币金额
