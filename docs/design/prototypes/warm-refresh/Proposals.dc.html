token / 组件变更提议

画布只用已确认的设计系统与 @xuanxue/ui 现有组件。下面是超出两者、或与 OpenSpec design.md 初稿不同的地方，逐项等使用者确认。项目 token 进 brand.css，新组件进 packages/ui/src/project/，不改模板文件。

A · token

编号提议说明
A1方向 C · 素（Graphite），两站共用中性色2026-11-17 使用者决定：放弃米色、奶油色与深红。浅色：底 #ffffff、表面 #f4f4f5、色带 #eaeaec、文字 #16181b / #4c5055 / #64686e、细线 #e1e2e5、输入框线 #7c8086。深色：底 #121315、表面 #1c1d20、色带 #26282c、文字 #ececee / #c4c6cb / #9c9fa5、细线 #2f3136、输入框线 #73777e。取代 design.md D1 的全部初稿值。
A2主按钮墨黑，强调色只作小标记primary #16181b（深色 #ececee），链接与正文同色并加下划线。accent：东方站松绿 #2f5d50（深色 #7fb8a4），用于印章、当前导航标记、工具卡字形、日主高亮；西方站黄铜 #8a6a1c（深色 #d2b15f），用于数字字形与星。illus 为中性灰（东 #9a9ea4、西 #a39a86）。design.md D2 的 --band 改用 surface-2。
A3标题改无衬线粗体，六个字号角色重定东方站 Noto Sans TC（韩语 Noto Sans KR）700：44 / 28 / 20 / 18 / 16 / 13（手机 display 32、title 24）。西方站全站 Manrope，标题 700：52 / 32 / 21 / 19 / 17 / 13（手机 36、26），display 与 title 字距 -0.02em。这改变了 design.md「不改字体家族」的非目标，需写入 design.md。
A4组件预览中的 14、15、28px 并入六角色设计系统的 ToolCard、Field 预览用了 14px 标签、15px 说明、28px 字形，与「每页不超过 6 种字号」冲突。画布改为：标签用 caption 13，卡片说明用 body，字形用 title。
A5命盘内大字使用 display / title工具页四柱干支与 Life Path 数字用 display；首页样例与报告里的小盘用 title。图形内文字仍在六角色内，度量测试无需例外。
A6五行色只作图表语义色，深色主题另有一组浅色沿用木 #3e7d4f、火 #b8432f、土 #9a7438、金 #6e7480、水 #2e5e8c；深色为 #6fb583、#e58a6f、#cfa35c、#a7adb8、#78a9dc（在深色三种底上均 ≥5.7:1）。只作圆点与条形并配文字标签，火色不作品牌或界面色。
A7手机间距补充设计系统未定义页面边距与手机的 space-block。画布取：页面边距桌面 32、手机 20；手机 space-block 32；手机卡片内边距 24（设计系统已给）。
A8圆角 6 / 14 / pill 与 shadow-raise 只在营销与工具页生效应用区（登录后）是否跟随由后续决定，默认不变。shadow-raise 只用于工具表单面板与展开的菜单，深色主题无阴影。
A9焦点环用文字色；新增 danger、on-danger焦点环为 2px 文字色、外移 3px，与控件之间留出页面底色间隙，黑色主按钮上同样可见。danger 是低饱和砖色，只用于表单错误与删除类操作：浅色 #96493d（白底 6.33:1、表面 5.76:1），深色 #d9988b（7.80:1、7.07:1）；on-danger 为 #ffffff / #121315，用于实心删除按钮。不是旧的品牌红，不作装饰。

B · 组件（新增于 packages/ui/src/project/，或改项目自有文件）

编号提议说明
B1Section、Prosedesign.md D6 已列。Section 统一区块间距 112 / 64；Prose 限宽 720。画布中色带不是整宽区块，而是页宽内的圆角条。
B2ToolCard字形、标题、一句话、文字链接；整卡可点。手机改为横排（字形在左），不显示第二个链接。
B3Band（今日条、一行价格共用）surface-2、radius-md、一行文字加一个文字链接；手机上下排列。今日条水合前后尺寸不变。
B4Segmented 分段切换用于曆法、性別与主题切换。优先复用现有 Tabs 与 ThemeToggle 的样式；不能复用时新增 project 组件。
B5Motif 插画每站一个母题，内联 SVG，线条用中性灰 illus。首页桌面 320px 在标题右侧，手机 168px 在标题上方。东方站松绿印章是唯一填充形；西方站只有星用黄铜描边。一页只出现一次。
B6页头手机面板与页脚设置行改现有 site-header、HeaderMenu（details）与 site-footer。面板含工具列表、主题切换、语言。西方站开始显示主题切换。取消浮动主题按钮。
B7八字表单重排原生 select 换成 Select；年、月、日为三个 Select。手机首屏只留出生日期、出生時間、性別、出生地与提交按钮；曆法并入日期标签行，真太陽時与時區收进「進階選項」。
