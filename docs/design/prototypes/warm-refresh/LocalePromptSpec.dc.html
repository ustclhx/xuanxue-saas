语言建议提示 · 位置、行为、无障碍、文案与提议

待确认（2026-11-20）。依据使用者当天定下的语言规则：/ 是两站的英文首页，其他语言在子目录；不自动跳转，不用 Cookie 或 JS 在同一地址切换语言；由客户端读取浏览器语言后给出提示，使用者点击才导航；提示不出现在服务端输出的 HTML 里；只建议本站已发布的语言；关闭后记住；载入时不引起版面位移。本组画板没有新增颜色、字号、圆角或阴影。

A · 位置：固定在视口底部的浮层（桌面居中、手机左右各留 12px）
方案结论理由
底部固定浮层采用position: fixed 的元素不占文档流，插入、关闭都不会移动页面上任何元素，版面位移（CLS）为 0。进出场只用 opacity 与 transform，这两项不计入位移。浮层在底部，不盖住页头与首屏 H1（LCP 元素）；文字面积小于 H1，不会成为新的 LCP 候选。水合后在浏览器空闲时才插入，不和首屏抢资源
顶部横幅，把页面往下推不采用现有模板横幅此前实测：水合后插入会把整页下推 97px（手机），CLS 0.118。要避免只能在服务端输出，而新规则不允许提示出现在服务端 HTML 里
水合后才占位的页内槽位不采用占位出现的那一刻，下方内容仍然会移动；提前在服务端留空位，则所有访客（包括不需要提示的）都看到一条空白
顶部固定浮层不采用同样没有位移，但会盖住页头导航和手机首屏的 H1；手机上底部更容易点到
页头语言控件旁的气泡不采用西方站页头目前没有语言控件；手机页头只有 56px，一句完整的话放不下
尺寸桌面手机
位置水平居中，距底部 24px左右各 12px，距底部 12px，另加 env(safe-area-inset-bottom)
宽与高随文字，最宽 600px；单行，高 62px宽 366px；文字最多 3 行，常见 2 行，高约 74px（不到视口高度的 9%）。两个候选时为两行，高约 110px
层级--z-sticky：在页面内容之上，在手机导航面板、对话框、弹层之下
外观与展开的菜单相同：浅色 surface 底 + shadow-raise，深色 surface-2 底、无阴影；圆角 radius-md（14px）；外框 line-strong 1px（深色没有阴影，靠这条线与页面分开）
动效出现：opacity 0→1 加上移 8px，200ms；prefers-reduced-motion 时只淡入。不自动消失
页脚不被挡住提示显示期间给 html 加 scroll-padding-bottom（等于提示高度 + 间距），键盘焦点滚动到的元素不会停在提示下面；这个属性不改变版面
B · 行为规则
项目规则
何时判断只在客户端：水合完成后，在浏览器空闲时读取 navigator.languages。服务端输出与预渲染的 HTML 里没有这个组件的任何标记
建议哪种语言按浏览器语言的先后顺序，取第一个能对应到本站已发布语言的：完整标签 → 语言加书写系统（zh-TW、zh-HK → 繁體中文；zh-CN、zh-SG → 简体中文）→ 主语言。它和当前页语言相同就不提示，也不再往后找（排在前面的才是使用者最想看的）
只建议已发布语言候选范围取站点配置里状态为已发布的语言。东方站：English、繁體中文、简体中文、한국어，日本語发布后加入；西方站：English，Español 发布后加入。两站互不建议
切换去哪当前页在目标语言下的对应地址（与 hreflang 相同）。按钮是真实的 <a href>，点击后整页导航。当前页没有对应译文时不提示
记住关闭点关闭或点切换后，在 localStorage 写一条记录（按站点各自保存，不用 Cookie），之后本站所有页面都不再提示。使用者在页脚或页头的语言控件里手动选过语言，同样写入这条记录。localStorage 不可用时仍然提示，关闭只在本次浏览内有效
搜索引擎容器带 data-nosnippet，提示文字不会被用作搜索摘要。爬虫不带中文、西语等浏览器语言，多数情况下不会触发
文案的语言提示用目标语言书写（看不懂当前页的人要能看懂提示），容器带 lang 属性。因此每个页面都要带上本站各语言的这 5 条短文案，不能只取当前页语言的 messages

D · 无障碍
项目做法
角色容器是 <section aria-label="Language suggestion">（region 地标，名称用目标语言），带 lang。不是对话框：不锁定焦点，不挡住页面操作
播报提示句所在的 <p> 是 role="status"（aria-live="polite"）：先插入空的容器，下一帧再填入文字，读屏在当前内容读完后播报一次，不打断
焦点出现时不移动焦点。用键盘关闭（焦点在提示内）后，焦点移到 <main>（tabindex="-1"），不丢失；用鼠标或触摸关闭时不动焦点
键盘路径DOM 位置在「跳至主要内容」链接之后、页头之前，所以 Tab 顺序是：跳至主要内容 → 切换 → 关闭 → 页头。焦点在提示内时按 Esc 等于关闭；不注册全局按键
触控目标切换按钮高 44px、最窄 64px；关闭按钮 44×44px；两者间距 8px 以上
可读名称切换：可见文字「Switch」，aria-label="Switch to English"（包含可见文字），带 hreflang。关闭：只有图标，aria-label="Dismiss"（各语言见下表）。地球图标是装饰，aria-hidden
对比度与焦点环文字 ink 在 surface / surface-2 上高于 4.5:1；焦点环 2px ink，外移 3px

G · 待确认的问题
问题本稿的做法
1 · 关闭记多久永久，按站点。另一种是 90 天后可再提示一次
2 · 当前页没有对应译文不提示。另一种是提示并带到目标语言的首页
3 · 不带地区的 zh 给两个候选并列给简体与繁体。另一种是按惯例直接当作简体，只给一个
4 · 提示句与按钮的写法提示句是问句（「…Switch?」），按钮是一个动词。另一种是提示句只陈述，按钮写全「Switch to English」
5 · 应用区是否显示只在公开页面（营销页、工具页、博客）显示；登录后的应用区按账号语言，不提示
6 · 是否等到首次操作再显示水合后空闲时即显示。另一种是等访客第一次滚动、点击或按键后才插入：爬虫渲染时完全看不到，但出现得稍晚
