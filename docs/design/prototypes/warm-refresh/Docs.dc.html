Getting started

The public API returns the same calculations the tools on this site use. This page shows one request from start to finish.

Make a request

Send the birth date as an ISO date. No key is needed for the free endpoints, which are rate limited per address.

GET /api/v1/numerology/life-path?date=1990-05-15

{
  "value": 3,
  "master": false,
  "steps": ["5", "15 → 6", "1990 → 19 → 10 → 1", "5 + 6 + 1 = 12 → 3"]
}

Read the response

value is the reduced number. master is true when the total stopped at 11, 22 or 33. steps lists each reduction in the order the life path number calculator shows them.

The endpoint paths above are placeholders: [API BASE PATH]. Check the Public API page for the current list.
