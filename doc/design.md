## 0. 项目定义

| 项 | 值 |
|---|---|
| 赛道 | AI 玄学/命理工具站，面向欧美与东亚市场 |
| 架构 | **两个主域名**：东方站 1 个、西方站 1 个；每个域名下用**语言子目录**（`/zh-hant/` `/ko/` `/fr/` …），**不开子域名** |

## 3. 英语骨架（主版 + 内链中枢）

**定位**：英语是**架构主版和内链中枢，不是流量最大的一版**。

| 词 | 量 | KD | 用法 |
|---|---:|---:|---|
| **life path number** | **90,500**（26-08；一年从 40,500 翻上来） | **35.5** | ✅ **首页主词** |
| numerology calculator | 33,100 | 待查 | ✅ 同页工具区 |
| numerology chart | 8,100 | 待查 | 内页 |
| name numerology | 5,400 | 待查 | 内页 |
| destiny / soul urge number | 各 1,600（soul urge +53%） | 待查 | 12 数字页 |
| angel numbers | 110,000 | 48.9 | 内容矩阵，**不做首页** |
| ace of spades meaning 族 | 5,400 | **15.9** | ✅ **52 张牌义页矩阵** |
| birth chart calculator | 165,000 | 待查 | ⚠️ 星盘线，另开 |

**首页对位样本 = `seventhlifepath.com`**：DR 37、16.6 年、41.1 万流量、**首页排第 1**，体验分 67（108 秒 / 2.2 页 / 跳出 45%）。
盘面判语原文要点：「**首页打内页**……是新站/小 DR 站反超老站内页的经典结构，而非靠外链体量取胜……**是后来者可复制的打法：用聚焦首页（最好域名直拼该词）正面对位它们的内页**」。
**窗口期证据**：该站当月从此词拿约 **2.1 万**流量，超过该词 12 个月均值 **1.4 万** → 「真实搜索量远高于年均值，词处于快速上升期，格局未固化，是新站入场的窗口期」。

**不做**：`tarot reading`（KD 59.9 红海）、`cafe astrology`（品牌词）、`numerology`（常规口径 KD 75.7，且 `numerology.com` 与词同名）、`astrology bot`（仅做 bot 才做）。

**变现必须认清**：`life path number` 顶部出价约 **$0.01~0.05**——英语是**流量词不是变现词**，收益在 L2/L3，不指望 AdSense。

## 8. 后续补证机制

**说明**：本站**没有对外开放的接口端点**，不存在可直接连的 MCP 服务。补证走下面两条路：

### 方式 A：浏览器插件（已有）
用于常规接口拿不到的两类数据：

| 能力 | 用途 |
|---|---|
| **读 Ahrefs** | 用自有 Ahrefs 账号读任意站的引荐域名 / 外链 / 流量曲线（本工具链无 Ahrefs 数据接口） |
| **读自有 GSC** | 收录原因、站点地图、人工处置、核心网页指标——只有 GSC 后台可见 |
| **打开受限页面** | 403 / 人机验证 / 需执行 JS / 需登录的页面 |

用法：本地 Agent 通过浏览器自动化驱动插件下达查询，或把待查 URL 列成清单批量执行。

### 方式 B：本地补齐（本轮缺口的正确解法）
以下三项**工具侧补不了，必须本地做**：

1. **台湾 / 韩国本地官方量**——工具侧传地区参数仍返回 us/en 库。**在 Keyword Planner 里手动切国家导出 CSV**（免费、几分钟、精度优于任何第三方估算）。
2. **法语各词的真实法国本地量**——**此前报的 18,100 属估算口径，已作废**（US 口径实测仅 210 / 50，而该口径不适用于法语词）。**立项前必须切「法国 + 法语」重核**，否则法语站的经济性判断不成立。
3. **tarot 词族一律不上规划师**——`tarot` / `tarot cards` / `tarot reading` / `tarot card meanings` / `tarot meanings` **五个词全部未收录或为 0，属系统性缺口**，非个例。**按 SERP 竞争 + KD 立项**，量级参考用 KD 报告估算值或第三方工具。

### 方式 C：清单回流
把「需上游核实」的项目攒成清单，一次性提交核查（KD 精评、SERP 解密、站点出词、规划师量、域名历史等）。**别一个词提一次。**
