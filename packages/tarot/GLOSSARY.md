# RWS 三語術語表

本包使用 1909 Rider–Waite–Smith 次序：力量 VIII、正義 XI。權杖 / 완드、聖杯 / 컵、寶劍 / 소드、錢幣 / 펜타클；正位 / 정방향、逆位 / 역방향。短義與 Yes/No/Maybe 為固定娛樂性編輯解釋，不預測未來；Death 表示結束與轉變，不指實際死亡。長文頁與專業母語編輯審閱屬後續內容任務。
