# @xuanxue/bazi

纯 TypeScript 排盘引擎：八字/사주、紫微斗数基础命盘、사주궁합。浏览器与服务端运行同一份代码，
同一输入得到逐字段相同的结构化 JSON。结果只含稳定 key（干支、五行、十神、神煞），不含文案；
页面按 `messages/<locale>/bazi.json` 渲染。

```ts
import { computeChart, computeCompatibility, validateInput } from '@xuanxue/bazi'
import { computeZiwei } from '@xuanxue/bazi/ziwei' // 单独入口，八字页不加载 iztro

const input = {
  calendar: 'solar', year: 1990, month: 5, day: 15,
  time: { hour: 10, minute: 30 }, // 不知道时辰传 null
  gender: 'male', location: { city: 'taipei' },
} as const
validateInput(input) // [] 或 [{ field, code }]，页面显示字段级错误
const chart = computeChart(input, { referenceYear: 2026 })
// 庚午 辛巳 庚辰 辛巳，起运 7 岁 3 个月，首步大运壬午（1997），日空申酉
```

`computeChart` 遇到非法输入抛 `BaziInputError`（`code = 'BAZI_INVALID_INPUT'`，`issues` 同
`validateInput`）。`referenceYear` 决定「当前流年」，由调用方传入，保证服务端复算一致。

依赖：`tyme4ts`（历法、节气、干支、童限）、`iztro`（紫微）；`lunar-javascript` 只作测试期 oracle。

## 版本

`ENGINE_VERSION`（`src/version.ts`）写入每个结果。计算规则、表格或输出结构变化时递增；
fixtures 需重新生成并在 PR 中说明差异。

## 1. 输入与校验

| 字段 | 规则 | 错误 |
|---|---|---|
| `year` | 1900–2100 | `year / out_of_range` |
| `month` `day` | 国历按当月天数；农历按该月大小（29/30 天） | `day / invalid_date` |
| `isLeapMonth` | 仅农历；该年闰月必须是所填月份 | `leapMonth / leap_month_not_exist` |
| `time` | 0–23 时、0–59 分；`null` 为不知道时辰 | `time / out_of_range` |
| `location` | 内置城市 id，或 `{ utcOffsetMinutes, longitude? }`（−12h…+14h） | `location / *` |
| `trueSolarTime` | 需要经度（城市自带；手选偏移需填经度） | `trueSolarTime / longitude_required` |

## 2. 时间换算

1. **农历 → 国历**：`LunarDay.fromYmd`（闰月用负月份）。
2. **当地钟表时间 → UTC 时刻**：按出生地历史时区表换算。
   - 时区表 `src/zones.data.ts` 由 `pnpm --filter @xuanxue/bazi generate:zones` 从 Node 自带的
     IANA tzdata 生成并提交；运行时不读 Intl 时区数据，避免各浏览器 tzdata 版本不同。
   - 20 个城市（台北/台中/高雄、香港、澳门、北京/上海/广州、首尔/釜山/大邱、东京、新加坡、
     吉隆坡、洛杉矶、温哥华、纽约、多伦多、伦敦、悉尼），1899-12 至 2101-01。
     覆盖台湾 1937–1945 UTC+9 与 1946–1979 夏令时、韩国 1908–1911 / 1954–1961 UTC+8:30 与
     1948–1951、1955–1960、1987–1988 夏令时、中国 1986–1991 夏令时等。
   - **夏令时判定**：tzdata 只给总偏移，生成时把「短于 300 天、且比前后两段都快」的时段视为夏令时，
     标准偏移取前一段。已知局限：二战期间英国双重夏令时会以 +1 为标准、美国战时时间视为标准时间。
   - 夏令时开始拨快造成的**不存在时间**按切换前偏移解释；回拨造成的**重复时间**取较早的夏令时解释。
   - 手选 UTC 偏移不含夏令时。
3. **当地标准时间** = UTC + 标准偏移（去掉夏令时）。例：1975-07-01 10:30 台北 → 09:30。
4. **真太阳时**（默认关闭）= UTC + 经度 × 4 分钟 + 均时差（NOAA 近似式，误差约 ±0.5 分钟），
   修正量取整到分钟后加到标准时间上，避免不同 JS 引擎三角函数末位差异影响结果。
5. **排盘所用时间**（`time.used`，结果页显示）：开启真太阳时为真太阳时，否则为当地标准时间。
6. **不知道时辰**：出生时刻按当地 12:00 估算，只用于年柱、月柱与起运（`fortune.approximate = true`）。

## 3. 四柱

- **年柱、月柱**：以出生 UTC 时刻与节气交接时刻比较（tyme4ts 节气以北京时间计，故把出生时刻换成
  北京时间再取 EightChar 的年/月柱）。年柱以立春交接时刻为界，月柱以「节」为界。真太阳时不改变年月柱。
- **日柱**：排盘所用时间的日期；**23 点起换日**（早晚子时不分，晚子时日柱取次日）。
- **时柱**：时支每两小时一支（23–1 点子时）；时干按五鼠遁：时干 = 日干 × 2 + 时支（mod 10）。

## 4. 藏干与十神

藏干取 tyme4ts，顺序为本气、中气、余气：

| 子 | 丑 | 寅 | 卯 | 辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 | 亥 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 癸 | 己癸辛 | 甲丙戊 | 乙 | 戊乙癸 | 丙庚戊 | 丁己 | 己丁乙 | 庚壬戊 | 辛 | 戊辛丁 | 壬甲 |

十神以日主对照目标天干：同我比劫、我生食伤、我克财、克我官杀、生我印；
与日主同阴阳取偏（比肩、食神、偏财、七杀、偏印），异阴阳取正（劫财、伤官、正财、正官、正印）。
日柱天干为日主，`tenGod = null`。

## 5. 五行计分、身强身弱、喜用神（参考）

- 天干每个 1.0；地支藏干本气/中气/余气 0.6/0.3/0.1，**缺少的气并入本气**，使每个地支合计 1.0
  （子卯酉本气 1.0；午、亥为 0.7 + 0.3）。
- **月令加权**：月支藏干 ×1.5（月干不加权）。
- 内部以 0.05 为单位整数运算；`percent` 保留一位小数。
- `count`：八字中各五行个数（天干按本身、地支按本气），无时辰为六字。
- **身强身弱**：同党 = 比劫（同我）+ 印（生我），含日主本身；同党占比 ≥ 50% 判身强。
- **喜用神（扶抑法，标注参考）**：身强取克泄耗（食伤、财、官杀），身弱取生扶（印、比劫）；
  `favorable` 按当前分数从低到高排序（首项用神、次项喜神），其余为 `unfavorable`。
  `strength.items` 给出每一项计分来源，供展示与 AI 详批引用。

样例 庚午 辛巳 庚辰 辛巳：金 4.75、火 2.2、土 1.15、木 0.3、水 0.1，同党 69.4% → 身强，喜用 水、木、火。

## 6. 大运与流年

- 阳年男、阴年女顺排，阴年男、阳年女逆排；从月柱起推十步。
- **起运**：出生时刻到前/后一个「节」的时长，按分钟精确换算（3 天 = 1 年、1 天 = 4 个月、
  1 时辰 = 10 天，即 lunar-javascript 流派 2 / tyme4ts `LunarSect2ChildLimitProvider`）。
  `startAfter` 给出年、月、日、时，页面通常显示「X 岁 Y 个月」。
- 每步大运给出干支、十神、起止年份（公历年）与起止虚岁，以及十个流年（按公历年取干支）。
- `currentYear`：`referenceYear` 的流年与所在大运序号（童限内为 `null`）。

## 8. 八字重量（称骨）

年（农历年干支）+ 农历月 + 农历日 + 时辰，单位钱，十钱一两；农历日期取排盘日（23 点后已换日），
闰月按所闰月份。范围二两一钱至七两一钱。表见 `src/weight.ts`。
无时辰时 `status = 'requiresHour'`，只给年月日三部分。

## 9. 不知道时辰

输出年、月、日三柱；`pillars.hour = null`，时柱十神不输出；五行与身强弱按六字计算；
神煞 `requiresHour = true`；八字重量 `requiresHour`；起运按 12:00 估算（`approximate`）。
紫微不出盘（`status = 'requiresHour'`）。

## 10. 紫微斗数（`@xuanxue/bazi/ziwei`）

同一 `BirthInput` 与时间换算，按排盘所用时间取 iztro 时辰序号（0 点早子、23 点晚子）；
输出十二宫（key、干支、是否身宫）、十四主星落宫与亮度、命宫/身宫地支、五行局与生年四化。

## 11. 사주궁합

基础 60 分，按双方日柱关系与五行互补加减，限制在 0–100，每项输出 `key / delta / detail`：

| 项 | 分 |
|---|---|
| 日干五合（甲己、乙庚、丙辛、丁壬、戊癸） | +15 |
| 日支六合（子丑、寅亥、卯戌、辰酉、巳申、午未） | +12 |
| 日支三合（同属申子辰/亥卯未/寅午戌/巳酉丑） | +8 |
| 日支相冲 | −15 |
| 日支相刑（子卯、寅巳申、丑戌未、辰午酉亥自刑） | −8 |
| 五行互补（双向各一项）：对方在我前两个喜用五行上的占比，40% 得满分 | 0…+10 |

## 12. 测试样例与双源校验

`test/fixtures/charts.json` 由 `pnpm --filter @xuanxue/bazi generate:fixtures` 生成：每个样例
分别用本引擎（tyme4ts）与 lunar-javascript 计算，逐字段一致才进入 `cases`，不一致的进入
`disagreements`（当前为空）。覆盖立春/节交接前后 1 分钟、子时跨日、闰月、台湾与韩国夏令时、
韩国 UTC+8:30、无时辰、真太阳时、南北半球夏令时城市、手选偏移与年份边界，共 51 个。

- 双源比对字段：排盘所用时间、四柱、农历日期、藏干、天干与藏干十神、日空/年空、大运顺逆、
  起运年月、十步大运干支与起止年份/虚岁。
- **取舍**：首轮生成时 28 个样例的起运「时」相差 2 小时（个别进位到「日」），原因是两库对节气
  间隔不足一分钟的秒数取整不同（流派 2 中 1 分钟 = 2 小时）。页面只显示到「岁 + 月」，
  故双源只比到起运年月，日/时以本引擎为准记入 `engineOnly`。调整后 51 个样例全部一致。
- 只由本引擎计算、记入 `engineOnly` 回归快照的项：神煞（空亡除外）、八字重量、身强弱、喜用神、
  起运日/时；它们的规则由 `test/rules.test.ts` 按上表逐项覆盖。
- 回归测试同时现算一次 lunar-javascript，防止 fixtures 与 oracle 漂移。
